## Gotchas / decisions
- Contrast fixes were made through tokens, as 04 requires; documented colour values changed slightly (see table). 04 section 13 token table should be read with these values.
- Dark theme had a real bug: `--card` stays cream in dark while `--text` turns cream, so buttons, inputs, pass button and reveal cards were unreadable (1.06:1). Fixed with `--on-card*` tokens.
- Scans wait for finite animations to finish; otherwise axe reads mid-fade colours on the reveal.
- The test starts its own mock on 8787 like the other specs; the Next dev overlay (`nextjs-portal`) is skipped in the focus walk.
